## 🚀 What I'm building

**[Yotakes](https://yotakes.vercel.app)** — *live in production*

The Letterboxd of restaurants. A trust network for people who actually eat out, built
around short reviews with photos instead of generic star averages. Seeded with 535 São
Paulo restaurants from Google Places, with row-level security on every table.

`Next.js 16` `TypeScript` `Supabase` `PostgreSQL` `Tailwind` `PostHog`

**Arremataí** — *private repo*

Arbitrage platform between Brazilian Federal Revenue auctions and Mercado Livre. Scrapes
auction lots, analyzes them with an LLM, computes the maximum profitable bid, then
publishes the won items back to the marketplace. Multi-tenant by JWT, Fernet-encrypted
OAuth tokens, 147 tests.

`Python` `FastAPI` `SQLAlchemy` `pgvector` `Next.js` `Docker`
